## ⚡ Overview

**SAM CODES** is a personal digital platform and client-conversion website engineered for **Samarth Nimangre (Sam)**. Built with modern web standards and AI-native patterns, the site bridges creative ambition with practical software execution — presenting functional AI workflows, automated business pipelines, and modern web applications with zero hype or fake claims.

### Core Architecture & Invariants

- **Zero-Fabrication Standard:** No mock testimonials, fake client logos, artificial metrics, or inflated skill ratings. Every project or experiment in the Lab clearly states its developmental status.
- **Evidence-First Lab:** Highlights active experimental builds, autonomous agent workflows, and web experiments with real verification blueprints.
- **Centralized Data Model:** All content, social handles, capabilities, services, and assistant knowledge bases are decoupled into structured TypeScript models inside `src/data/`.
- **Interactive "Ask Sam" Assistant:** An on-page intelligent Q&A terminal grounded exclusively in verified facts about Sam's stack, availability, process, and background.
- **Cinematic Neural Canvas:** Custom ambient HTML5 canvas background with responsive node scaling, mouse interaction, and `prefers-reduced-motion` compliance.

## 🛠️ Technologies & Stack

### Building With
- **Framework & Runtime:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack, React 19)
- **Language:** Strict [TypeScript](https://www.typescriptlang.org/) (Strict null checks, zero `any`)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (Oxide CSS-first engine)
- **Icons & Motion:** [Lucide Icons](https://lucide.dev/), Canvas API
- **AI Integrations:** OpenAI API, Anthropic Claude API, DeepSeek, LangChain
- **Automation & APIs:** Make (Integromat), n8n, Webhooks, RESTful APIs
- **Database & Storage:** Supabase, PostgreSQL

### Actively Exploring
- Autonomous Multi-Agent Orchestration
- Local LLMs (Ollama, vLLM)
- Fast RAG & Semantic Vector Indexing
- Embedded WASM Kernels

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- `pnpm` (recommended) or `npm`

### Installation
```bash
# Clone the repository
git clone https://github.com/Sam-CodesAI/Sam-Codes.git
cd Sam-Codes

# Install dependencies
pnpm install # or npm install

# Start development server
pnpm dev # or npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build
```bash
# Verify type safety and generate production bundle
pnpm build # or npm run build
```
