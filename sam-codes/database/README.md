# 🗄️ SAM CODES // Database & Persistence Layer

The database layer manages data persistence, relational integrity, zero-downtime schema evolution, and TypeScript contract definitions across Supabase PostgreSQL and local fallback ledgers.

---

## 1. Directory Structure

```
database/
├── supabase/
│   ├── migrations/             # Timestamped Immutable SQL Migrations
│   │   ├── 20260905_command_center.sql              # Initial schema: projects, services, inquiries, profile
│   │   ├── 20260906_harden_security.sql             # Row Level Security (RLS) policies and admin gates
│   │   ├── 20260907000000_fix_project_constraints.sql # Constraints, foreign keys, and indexes
│   │   └── 20261104_unify_ecosystem.sql             # Unified tables for assistant, analytics, and CRM
│   └── seed.sql                # Default initial relational records for production bootstrap
├── types/
│   └── database.types.ts       # Autogenerated TypeScript type contracts for all PostgreSQL tables
├── data/
│   └── app-store.json          # Offline-first local JSON fallback ledger (zero-downtime guarantee)
└── scripts/
    └── backup-db.ts            # Automated database snapshot script with timestamped exports
```

---

## 2. Table Topology & Relational Architecture

- **`profile`**: Stores the founder bio, avatar URL, availability status flag, and geographic coordinates.
- **`projects`**: Stores flagship software systems, slug routes, GitHub URLs, live links, and tech stack tags.
- **`services`**: Stores client service packages, descriptions, deliverables, and dual-currency rates (USD & INR).
- **`inquiries`**: CRM ledger tracking inbound client leads, project briefs, contact details, and fulfillment statuses.
- **`assistant_knowledge`**: Document vectors and Q&A ground-truth pairs for the Ask Sam assistant.
- **`analytics_events`**: Privacy-first telemetry recording views, referral domains, and action clicks.
- **`socials`**: Links to verified external profiles (GitHub, LinkedIn, Telegram, X, Reddit).
